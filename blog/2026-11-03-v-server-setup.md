# New Project: V-Server Setup 🖥️

I've added **V-Server Setup** to my developer portfolio!

As part of my DevSecOps training, I configured a Linux virtual server for remote administration and future application deployments.

The project covers SSH key authentication, disabling password-based SSH login after verification, hosting a custom page with NGINX, and configuring Git and GitHub access on the server.

This setup later became the foundation for deploying my Django-based Baby Tools World application.
