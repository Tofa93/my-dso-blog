Another project completed as part of my DevSecOps learning journey!

This time, I built and deployed a custom Minecraft Java Edition server using Docker, Alpine Linux, and Java 25.

<!-- truncate -->

The project focused on:

- Building a custom Docker image
- Configuring environment variables
- Managing persistent storage
- Implementing automatic container recovery
- Deploying and testing the server on a cloud VM

The server was successfully tested using both the Minecraft client and a Python-based status check.

The complete development and deployment documentation is available in the Projects section.
